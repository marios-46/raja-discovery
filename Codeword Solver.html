Codeword Solver

Instructions: Type the letters you know. Use . or ? for a unique unknown letter, and digits 1-9 for repeated unknown letters (same digit = same letter, different digit = different letter).
Examples: 11.E matches "ooze", 112.2 matches "llama", ..A122.1R matches "chauffeur".

The built-in list is only a small sample. Click Load word list… and choose any .txt file with one word per line (for example words_alpha.txt from the dwyl/english-words GitHub repo) to search a full dictionary. The file stays in your browser.
